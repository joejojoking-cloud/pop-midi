# 华语流行歌 MIDI 曲库

909 首华语流行歌 MIDI，浏览器内用 SoundFont 实时合成试听，支持单曲与整包下载。

- `index.html` / `app.js` / `style.css` — 前端，无后端
- `data.json` — 曲目索引（歌名 / 歌手 / 地区 / 时长 / 大小）
- `midi/` — 909 个 MIDI 文件
- `assets/TimGM6mb.sf2` — GM SoundFont（试听用）
- `downloads/pop909-midi.zip` — 全部曲目打包（4.6 MB）

数据来源：POP909 数据集（music-x-lab，909 首华语流行歌，主旋律 + 伴奏 + 和弦标注，学术开源）。
