# 大陆与港澳流行歌 MIDI 索引

28 位大陆与香港歌手的 882 条 MIDI 条目，按下载量排序，支持按歌名/歌手/地区/时长检索。

**本站只做索引，不托管任何 MIDI 文件。** 每条目跳转到 MidiShow 原页，文件由源站提供（下载消耗 3 积分/首，注册验证邮箱赠 5 积分）。

- `index.html` / `app.js` / `style.css` — 前端，无后端
- `data.json` — 曲目索引（歌名 / 歌手 / 地区 / 时长 / 大小 / 下载量 / 评分 / 源站链接）
- `data/raw.json` — 抓取原始数据（在上一级目录）
